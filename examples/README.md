# Synthetic examples

`synthetic-group-reference.json` is fabricated for contract and gate demonstration. It contains no company, policy, metric, document identifier, or wording copied from the licensed internal source.

The fixture tests two difficult reference types:

- a plural anaphor that must resolve to two explicitly named organizations;
- a complement group whose actual members are unknown but whose exclusions are explicit.

Run `python scripts/validate_synthetic_fixture.py` from this release-preparation directory.
